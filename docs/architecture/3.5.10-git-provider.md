## Thesis

The git provider (`pkg/op/provider/git`, `op.RoleAction`) manages git repositories as
graph resources: one compensable acquisition (`git.clone`), two fallible movements (`git.checkout`, `git.pull`), and
one fact reader (`git.observe`).

Design points:

1. **A repository's identity is its location; its content identity is its state.** `git.Resource` addresses by
   location, and layers the content-identity surface on top: `Digest` is the SHA-256 over HEAD for a clean repo —
   stable across calls, changed by commits, and **different when dirty** — while `Etag` is the cheap screen (HEAD
   short id, plus a status fingerprint when dirty). This is the as-deployed record the trace's ledger snapshot
   captures (phase-8 step 48).
2. **Clone is the compensable step.** `Clone` carries the full acquisition surface (`directory?`, `bare?`,
   `branch?`, `depth?`, `filter?`, `no_checkout?`, `no_tags?`, `origin?`, `recurse_submodules?`, `single_branch?`,
   plus `**kwargs` passthrough), stamps the producer, and returns a `*Receipt`; `CompensateClone` removes the
   cloned directory. `Checkout` and `Pull` mutate an *existing* repo the plan already owns — fallible, not
   compensable.
3. **Receipts round-trip through the catalog.** `Receipt.RestoreEncoded` resolves the repository resource via the
   catalog's URI→id namespace (phase-8 step 44 — which also fixed the provider onto `exec.CommandContext`, so run
   cancellation reaches git subprocesses).
4. **Observation is a fact, not a resource** ([4-resource-management](4-resource-management.md) §6.1):
   `git.Observation` records `ObservedHEAD`, `ObservedRef`, `Bare`, `Dirty`, and the `Remotes` map at a moment.

## API surface

```go
func (p *Provider) Clone(activationRecord *op.ActivationRecord, repository string,
	/* options */ ...) (*Resource, *Receipt, error)                     // git.clone(repository, ...options)
func (p *Provider) CompensateClone(activationRecord *op.ActivationRecord, receipt *Receipt) error
func (p *Provider) Checkout(repo *Resource, ref string) (*Resource, error) // git.checkout(repo, ref)
func (p *Provider) Pull(repo *Resource) (*Resource, error)                 // git.pull(repo)
func (p *Provider) Observe(repo *Resource) (*Observation, error)           // git.observe(repo)
```

A command hook seam makes `Clone` testable without a network (`TestClone_HookReceivesArgv` and kin assert the built
argv, option mapping, and error propagation).
