## Thesis

The regexp provider (`pkg/op/provider/regexp`, `op.RoleModule|op.RoleAction`) is Go
regular-expression text processing for plans and programs: eight pure/fallible operations over `(pattern, text)`
with **compiled-pattern caching** — a repeated pattern compiles once per provider instance. No resources, no
receipts, no side effects.

## API surface

```go
func (p *Provider) Match(pattern, text string) (bool, error)                          // regexp.match
func (p *Provider) Find(pattern, text string) (string, error)                         // regexp.find
func (p *Provider) FindAll(pattern, text string, count int) ([]string, error)         // regexp.find_all
func (p *Provider) FindSubmatch(pattern, text string) ([]string, error)               // regexp.find_submatch
func (p *Provider) FindAllSubmatch(pattern, text string, count int) ([][]string, error) // regexp.find_all_submatch
func (p *Provider) Replace(pattern, text, replacement string) (string, error)         // regexp.replace ($1 expansion)
func (p *Provider) ReplaceLiteral(pattern, text, replacement string) (string, error)  // regexp.replace_literal
func (p *Provider) Split(pattern, text string, count int) ([]string, error)           // regexp.split
```

`Replace` expands submatch references in the replacement; `ReplaceLiteral` does not. `count` follows Go's
convention (negative = all).
