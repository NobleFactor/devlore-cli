None for this provider.

Two findings from landing root placement belong elsewhere and are filed:

- **#706** — `pkg/op/provider/ui/testdata/integration.star` was deleted here: it called `ui.success(...)`, a
  method that does not exist, and claimed to exercise "all five messaging methods" when there are six. No Go
  test ever loaded it. Fourteen sibling providers carry the same orphaned fixture, 305 lines in total, and
  `docs/plans/add-test-coverage.md` marks that work complete when it is not.
- **The two-pass landing property**, recorded in the architecture document: `star/extensions/*.star` is both
  the generator's input and a consumer of the API it emits, so a change to a provider's Starlark surface that
  the generator's own extensions use cannot land in a single pass. Nothing else documents this.
