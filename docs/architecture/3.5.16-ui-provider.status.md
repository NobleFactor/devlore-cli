## Outstanding

**Root placement is designed but not landed** — [#698](https://github.com/NobleFactor/devlore-cli/issues/698),
task [#700](https://github.com/NobleFactor/devlore-cli/issues/700), plan
[`docs/plans/ui-at-root.md`](../plans/ui-at-root.md). Until it lands, `print` and `fail` in Starlark are the
`starlark-go` builtins and bypass the narrator entirely — so the uniformity the architecture document claims
holds for `ui.print(...)` but **not** for a bare `print(...)`.

Landing it carries two known consequences, both recorded on #700: every `ui.*` call site in the tree (231 of
them) must move to a bare name, and `placeModule`'s root path has a latent `return`-for-`continue` defect that
putting `ui` at root would arm.
