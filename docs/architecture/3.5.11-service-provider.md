## Thesis

The service provider (`pkg/op/provider/service`, `op.RoleAction`, `+devlore:access=planned`) is platform-agnostic
service management: five compensable state changes (`start`, `stop`, `enable`, `disable`, `restart`) and three
predicates (`enabled`, `exists`, `running`). Platform specifics are **delegated entirely** to
`Platform.ServiceManager` on the runtime environment ([3.4](3.4-platform-package-managers.md)) — the provider owns
the saga contract, not the systemctl/launchctl divergence.

Design points:

1. **The receipt records prior state, so compensation is semantic.** Each state change captures what was true
   before it (the `was_running` / `was_enabled` record — phase-8 step 44's `RestoreEncoded` alignment); the
   compensating action restores *that*, not a blind inverse — a `Start` of an already-running service compensates
   to a no-op.
2. **`CompensateRestart` is a no-op by design**: a restarted service was already running, so the pre-state and the
   post-state agree; there is nothing to restore.
3. **Services are tag-URI resources** (`svc:` scheme), addressed by name, rehydrated through the catalog — the
   step-44 fix resolves them via the catalog's URI→id namespace rather than discovery.

## API surface

```go
// Compensable pairs (each: (activation, name *Resource) -> (*Resource, *Receipt, error) + a Compensate companion)
Start / CompensateStart       // service.start(name)
Stop / CompensateStop         // service.stop(name)
Enable / CompensateEnable     // service.enable(name)
Disable / CompensateDisable   // service.disable(name)
Restart / CompensateRestart   // service.restart(name) — compensation is a deliberate no-op

// Predicates (fallible reads)
func (p *Provider) Enabled(name *Resource) (bool, error) // service.enabled(name)
func (p *Provider) Exists(name *Resource) (bool, error)  // service.exists(name)
func (p *Provider) Running(name *Resource) (bool, error) // service.running(name)
```
