## Outstanding / open questions

None — the §10 round closed 2026-07-18 and S7 landed the same day. The historical rulings:

1. ~~Special entry types~~ — RULED 2026-07-18 (design §10.1, 1a–1c): symlinks extract via `file.Link` with
   contained targets (absolute/escaping = error); hardlinks materialize as content copies of their extracted
   referent; devices/FIFOs/sockets error; silent skipping ends. Implemented (S7, 2026-07-18).
2. ~~Total-extraction cap~~ — RULED 2026-07-18 (design §10.2): no caps; ENOSPC + the removal-first unwind are
   the real mechanism (tar precedent, minus tar's partial-extraction mess). The per-entry `maxEntryBytes`
   `LimitReader` wraps are a silent-truncation defect and are deleted. Implemented (S7, 2026-07-18).
3. ~~`filepath-securejoin` adoption~~ — RULED 2026-07-18 (design §10.3): adopt as a divergence detector inside
   a three-layer story — escape intent errors (layer 1), lexical-vs-resolved divergence errors (layer 2,
   SecureJoin; no silent skip, no silent redirect), `os.Root` backstops confined sessions (layer 3, already
   in place). Implemented (S7, 2026-07-18).
4. ~~Format-mismatch diagnostics~~ — RULED 2026-07-18 (design §10.4): first-header failures name the detected
   outer format and the missing container; the empty decompressed payload errors instead of succeeding with
   zero entries; later corruption keeps its cause under the format prefix. Implemented (S7, 2026-07-18).
5. ~~Streaming zip~~ — RULED 2026-07-18 (design §10.5): never — the central directory stays the sole authority
   (parser-differential safety), and stream-shaped sources spool to disk. The §10 round is CLOSED; S7 carries
   the implementation of rulings 1–4 plus the sanctioned stream-input add.
