## Thesis

The powershell provider (`pkg/op/provider/powershell`, `op.RoleAction`, `+devlore:access=planned`) is PowerShell 7+
command execution: one action, `powershell.exec`, running `pwsh -NoLogo -NoProfile -Command <command>`.

Design points:

1. **`pwsh` is hard-required; Windows PowerShell is not supported.** PowerShell 7+ is cross-platform — `pwsh` runs
   on Windows, macOS, and Linux — so the provider is platform-agnostic, requiring only `pwsh` on PATH. There is
   deliberately **no fallback** to the legacy Windows-only `powershell.exe` (PowerShell 5.x) — a capability ruling
   (phase-8 step 28), not an omission.
2. **The shell provider's contract otherwise**: not compensable (the same arbitrary-command reasoning), the same
   `*Result` emission shape (command / exit code / stderr / stdout, `json`/`yaml`/`csv`-tagged), the same
   context-bound subprocess (`exec.CommandContext` — run cancellation reaches the child).
3. `-NoLogo -NoProfile` keeps execution hermetic of user profile state.

## API surface

```go
func (p *Provider) Exec(command string) (*Result, error) // powershell.exec(command)

type Result struct {
	Command  string
	ExitCode int
	Stderr   string
	Stdout   string
}
```
