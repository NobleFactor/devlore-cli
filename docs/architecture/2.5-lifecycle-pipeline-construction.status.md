## Document Discrepancies

The document describes the target model. The framework prereq is in place; the command-side construction is the
in-progress work tracked by
[`../plans/extract-starlark-from-op/phase-8/lore-command-rewrites.md`](../plans/extract-starlark-from-op/phase-8/lore-command-rewrites.md).
Where the document and the code disagree:

- **2026-09-30 — a phase's cascade: one runtime and one `run`, or one runtime per script.** § Platform-layered script
  selection says a phase's scripts are loaded into one planning runtime, general to specific, sharing a namespace, the
  general layers contributing definitions the specific ones build on, and that exactly one script in the cascade
  defines `run`: none means the phase is absent, more than one is an error. § Go ↔ Starlark during planning and
  § Construction restate it. The code runs each selected directory's `<phase>.star` in cascade order, each on its own
  runtime with its own globals, and calls the phase-named function in every one (`install(package, phase)`):
  `Release.PhaseActions` makes one `ScriptAction` per script, and `executeScriptAction`
  (`cmd/lore/lore/builder.go`) executes the file on a fresh runtime from `prepareScriptEnv` and fails the build when
  the script doesn't define the function. No definition passes from one layer's script to the next. Found during
  #944, which changed which directories are selected and in what order but not how their scripts run; left for the
  owner to rule. The document is not rewritten meanwhile.
- **2026-09-30 — phase isolation: `Clear()` or parent stamping.** § Go ↔ Starlark during planning and § Construction
  say the invocation registry is harvested into the phase's subgraph and then `Clear()`ed before the next phase. The
  code never clears it. `buildPackage` (`cmd/lore/lore/builder.go`) takes the invocations whose `Target` has no
  parent as the phase's children (`parentlessTargets`), and building the phase subgraph stamps their parent, so the
  next phase sees only its own. Isolation holds; the mechanism differs. Found during #944; the document is not
  rewritten meanwhile.
