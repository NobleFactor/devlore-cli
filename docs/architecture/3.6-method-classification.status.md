# Method Claims — deterministic, idempotent, sandboxed — Status

**Architecture document:** [3.6-method-classification.md](3.6-method-classification.md)
**State:** **implemented 2026-08-26** ([#677](https://github.com/NobleFactor/devlore-cli/issues/677)). A provider
method states the guarantees it makes; codegen refuses one its signature contradicts, and `pkg/op/claimcheck`
holds the rest to the call graph. `make check` gates both.

The filename retains `method-classification` so inbound links keep resolving. The document it names was replaced,
not amended: its first draft designed three exclusive tiers — `pure` / `query` / `action` — which were rejected on
2026-08-26 and are recorded in §8 rather than discarded.

## What the claims found

Annotating was not bookkeeping. Each of these was invisible until something asserted a property that could be
contradicted:

| Finding | Issue |
| --- | --- |
| `file.Glob` used `filepath.Glob` — absolute patterns honored verbatim, `..` surviving `Join`'s clean, symlinks followed out | [#687](https://github.com/NobleFactor/devlore-cli/issues/687), fixed |
| `walkDir` fell back to `filepath.WalkDir` whenever no root existed | [#687](https://github.com/NobleFactor/devlore-cli/issues/687), fixed |
| `applyOwnership` called `os.Chown` while `fsroot.Dir` has one — the only file mutation leaving the sandbox | fixed 2026-08-26 |
| Every graph's checksum embedded `time.Now()`, so no two identical plans agreed | [#690](https://github.com/NobleFactor/devlore-cli/issues/690), fixed |
| Four methods read machine-local config while planning | [#694](https://github.com/NobleFactor/devlore-cli/issues/694), open |
| `template.Env` reads the ambient environment | [#683](https://github.com/NobleFactor/devlore-cli/issues/683), open |
