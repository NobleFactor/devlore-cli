## Thesis

The shell provider (`pkg/op/provider/shell`, `op.RoleAction`, `+devlore:access=planned`) is POSIX command execution
for the graph: one action, `shell.exec`, running `sh -c <command>` — POSIX semantics on Linux, macOS, and any
platform with `sh` on PATH.

Design points:

1. **The escape hatch is deliberately not compensable.** `Exec` is a fallible action with no `Compensate` pair —
   an arbitrary command's semantic inverse is unknowable, so the framework does not pretend otherwise
   ([2.2](2.2-phase-execution.md)). Authors needing rollback pair the command with an explicit inverse in an error
   action.
2. **One emission shape.** The action returns a `*Result` — the original command, both captured streams, and the
   subprocess exit code — tagged for `json` / `yaml` / `csv` so one value serves the `result.Sink` emit and the
   downstream promise alike.
3. **Cancellation flows.** The subprocess runs under `exec.CommandContext` bound to the runtime environment's
   context, so a run stop or cancel reaches the child process.

## API surface

```go
func (p *Provider) Exec(command string) (*Result, error) // shell.exec(command)

type Result struct {
	Command  string // the command string passed to the shell
	ExitCode int    // subprocess exit code; 0 on success
	Stderr   string // captured stderr
	Stdout   string // captured stdout
}
```
