## Thesis

The flow provider is the **root provider** (`+devlore:root=true`): its actions are the graph's **orchestration
combinators**, promoted flat onto the Starlark surface as `plan.subgraph`, `plan.gather`, `plan.choose`,
`plan.wait_until`. Unlike a resource provider (file, archive), it produces no resources and mutates no state of its own —
it *shapes and drives execution*.

One idea carries the whole design:

**Every combinator is a subgraph.** `Subgraph` is the base case — run a body once. `Gather`, `Choose`, and `WaitUntil`
are **quantifiers over it**: they run the same body-walk a bounded number of times and differ only in *how many* and
*why they stop*.

| Combinator | Runs the body | Stops when |
|------------|---------------|-----------|
| `Subgraph` | once (K = 1)  | the body completes |
| `Choose`   | one branch (K = 1) | the first case whose `when` is truthy runs its `then` — else the default |
| `Gather`   | once per item (K = N) | every item's iteration completes |
| `WaitUntil`| repeatedly (K = 1+) | the body is truthy, or a timeout elapses |

Because they share one execution mechanism (§3), the provider stays small: four thin methods over the same
per-subgraph-executor, stamped-recovery-stack core.

## 1. Role in the execution graph

Every combinator's bound `Unit` is an `*op.Subgraph`, and every combinator is a **Compensable** action returning the
saga shape:

```
(any, *op.RecoveryStack, error)
```

The `any` is the combinator's terminal result; the `*op.RecoveryStack` is its compensation state — the stack the
executor owns for this subgraph, returned as the action's compensator so a later failure can roll the whole thing back.
Each combinator has a `Compensate<Name>` companion that undoes it; because the compensator is always a recovery stack,
every companion collapses to `stack.Unwind(activation.RuntimeEnvironment)`.

## 2. The construction pattern

The Starlark surface builds the topology; the runtime method walks it. Each combinator adopts its **body** — a list of
`plan.*` invocations — as the children of its subgraph:

- `plan.subgraph(body=[...])` — the children are the body.
- `plan.gather(items=[...], body=[...], limit=N)` — the children are the body, dispatched once per item.
- `plan.choose(default=<body>, plan.case(when=<body>, then=<body>), ...)` — the **case statement** is a construction
  aid: it pairs a `when`-subgraph with a `then`-subgraph per case, plus a default subgraph, so the topology carries
  choose semantics (§6).
- `plan.wait_until(body=[...], timeout=, interval=)` — the body is a predicate re-evaluated each poll (§7).

The planners (`ChoosePlanner`, `GatherPlanner`, `SubgraphPlanner`, `WaitUntilPlanner`) build the `*op.Subgraph`; the
provider methods run it.

## 3. Execution model — per-subgraph executor + stamped recovery stacks

This is the shared core (phase-8 step 31) all four combinators build on.

- **Executor ownership.** Each subgraph runs via its **own child executor**, which *owns* the recovery stack scoped to
  its saga boundary. The framework supplies that stack as `activation.Stack` — a fresh stack on a first dispatch, or, on
  resume, the restored stack from the trace. A combinator **takes** `activation.Stack`; it never mints
  `op.NewRecoveryStack()`.
- **The shared body-walk.** `walkSubgraphChildren` dispatches a subgraph's children in order on a given stack and frame.
  `Subgraph` calls it once; `Gather`/`Choose`/`WaitUntil` call it once per body-run. It is the single implementation of
  "run a body."
- **Stamped substacks.** A combinator that runs the body more than once runs each on its **own child stack**
  (`op.NewChildRecoveryStack`), then **stamps** that stack ([`RecoveryStack.Stamp`]) with the run's identity, result,
  and status, and nests it onto `activation.Stack`. A stamped stack carries the receipt's outcome subset — `unitID`,
  `result`, `resultType`, `err` — *as its own fields*; it does **not** embed a receipt, because a stack undoes itself
  via `Unwind` and so needs identity, not a named compensator.
- **Compensation.** `Compensate<Name>(activation, stack)` is `stack.Unwind(activation.RuntimeEnvironment)`. Unwind walks
  every nested substack LIFO, so a combinator's rollback cascades through each body-run that happened.
- **Resume.** Each body-run's stamped substack is its resumption point. On re-entry the combinator classifies each run
  against the adopted stack (`RecoveryStack.NestedStackByUnitID`): a completed run **replays its stamped result** and is
  skipped, a paused run is **adopted in place and re-entered**, an un-run body runs fresh. Nothing already done
  re-executes.

## 4. Subgraph — the base case

```go
func (p *Provider) Subgraph(activation *op.ActivationRecord, kwargs map[string]any) (any, *op.RecoveryStack, error)
```

Binds `kwargs` to the subgraph's declared parameters (layered onto the inherited variable frame), walks the children
once on `activation.Stack`, and returns that stack. The terminal child's result bubbles up as the subgraph's result.
`CompensateSubgraph` unwinds the stack. This is the primitive the other three quantify over.

## 5. Gather — the N-quantifier (implemented, step 31.2)

```go
func (p *Provider) Gather(activation *op.ActivationRecord, items []any, kwargs map[string]any) (any, *op.RecoveryStack, error)
```

Runs the body **once per item**, concurrently up to `limit` (default: the platform's concurrency). Each iteration binds
`item` into its frame (`plan.variable("item")`), walks the body on its **own** child stack, and — on the dispatching
goroutine, so `activation.Stack` stays single-writer — stamps that substack with `"<gatherID>#<i>"` and nests it in
index order. The result is a `[]any` indexed by item order.

On resume, a completed iteration replays its stamped result and is skipped; a paused iteration is adopted and
re-entered; unrun iterations run fresh — so a re-entered gather finishes only what was unfinished. Compensation unwinds
every iteration's substack (including a falsy branch's, since it ran) in reverse. Proven by
`TestGather_Resume_ReplaysCompletedIterations` and `TestGather_Resume_ReentersPausedIteration`.

## 6. Choose — a binary decision tree (implemented 2026-07-02, step 10)

**`flow.Choose` does nothing but execute the graph** — it shares `Subgraph`'s body. All the logic is in the topology
`ChoosePlanner` builds at plan time: a **binary decision tree**. Each case is a `when`-subgraph (a decision node) paired
with a `then`-subgraph (a leaf), plus a default subgraph (a leaf). Because the cases are known at plan time (unlike
Gather's runtime N), the full tree is built in advance and the method just runs it. The target action is the Subgraph
shape:

```go
func (p *Provider) Choose(activation *op.ActivationRecord, kwargs map[string]any) (any, *op.RecoveryStack, error)
```

The tree is wired with **conditional edges** — `op.Edge` gains a `Guard` (`GuardTruthy` / `GuardFalsy`; the zero
value `GuardNone` is an unguarded ordering edge):

```
when₀ ───truthy───► then₀ (leaf)
  └─────falsy────► when₁ ───truthy───► then₁ (leaf)
                     └─────falsy────► … ── whenₙ ───truthy───► thenₙ (leaf)
                                              └─────falsy────► default (leaf)
```

Executing the graph is a tree traversal (`walkSubgraphChildren` gains a decision-tree branch when a subgraph carries
conditional edges): run `when₀`, read `isTruthy`, follow the matching branch, land on a leaf. Only the path taken runs —
so an unchosen or after-the-match branch never executes (`TestChoose_UnchosenInvocationBranchDoesNotRun`). The nodes on
the path leave ordinary receipts on `activation.Stack`; `CompensateChoose` unwinds them; a reload re-derives each
branch by running `isTruthy` on the node's round-tripped result (step 42 slice 2c, 2026-07-12 — supersedes the earlier
decision to stamp a decision node's evaluated `GuardResult` and replay the recorded path). Guarded edges must form a well-formed decision tree — `validateGuardedEdges`
enforces the shape at both `ValidateGraph` boundaries (plan-seal and load), so a malformed document (a cycle at a
decision point, a double-truthy edge, an unreachable child) is rejected at load rather than mis-walked. Ordering-edge
cycles in run-all subgraphs get the same load-time rejection. Cycle rejection is scoped, not final: loops via guarded
back-edges are the anticipated extension — a future loop construct legalizes its own well-formed cycles with
iteration-scoped receipts and a mandatory runtime budget (see step 10's anticipated-extension note).
Unguarded edges (`GuardNone` — every existing subgraph) keep running all their children unchanged, so
`Subgraph`/`Gather` are untouched.

Implemented 2026-07-02: the decision-tree walk (`walkDecisionTree` / `root` / `branch` behind `hasConditionalEdges`),
the tree-building `ChoosePlanner`, and `flow.NewCase` + `plan.case` are landed, with bodies accepted as invocation
lists, singletons, or lambdas — a lambda desugars to the new `function.call` leaf, archived as a content-addressed
`function.Resource`. The goal proof `TestChoose_UnchosenInvocationBranchDoesNotRun` is green. `isTruthy` reads `when`
results in the traversal; WaitUntil uses it for its poll test. Design + plan:
[10-plan-choose.md](../plans/extract-starlark-from-op/phase-8/steps/10-plan-choose.md).

## 7. WaitUntil — the poll-until-truthy quantifier (implemented 2026-07-02, step 12)

```go
func (p *Provider) WaitUntil(activation *op.ActivationRecord, timeout, interval time.Duration, kwargs map[string]any) (any, *op.RecoveryStack, error)
```

Runs the body **repeatedly** until its result evaluates truthy (`isTruthy`) or `timeout` elapses, sleeping `interval`
between polls — a K = 1+ quantifier over Subgraph, re-evaluating the container each poll. `body=` takes the same
shapes case bodies take (invocation list, singleton, or lambda via the `function.call` leaf); `timeout=` is required.
Each poll runs on a scratch child stack: falsy polls drop unrecorded (the body is expected side-effect-free; nothing
enforces it), the truthy run's stack stamps the unit's own ID and nests, timeout fails with a plain error carrying the
poll count and last falsy result, and resume re-enters fresh with the full budget. The loop lives in the method by the
same criterion that put Gather's there — the poll count is runtime-unknown; the guarded back-edge loop remains step
10's anticipated future construct.

## 8. API surface

```go
// Combinators (Compensable actions). Each returns the saga shape; each has a Compensate companion.
func (p *Provider) Subgraph (activation *op.ActivationRecord, kwargs map[string]any) (any, *op.RecoveryStack, error)
func (p *Provider) Gather   (activation *op.ActivationRecord, items []any, kwargs map[string]any) (any, *op.RecoveryStack, error)
func (p *Provider) Choose   (activation *op.ActivationRecord, kwargs map[string]any) (any, *op.RecoveryStack, error)
func (p *Provider) WaitUntil(activation *op.ActivationRecord, timeout, interval time.Duration, kwargs map[string]any) (any, *op.RecoveryStack, error)

// Companions -- each unwinds activation.Stack.
func (p *Provider) CompensateSubgraph (activation *op.ActivationRecord, stack *op.RecoveryStack) error
func (p *Provider) CompensateGather   (activation *op.ActivationRecord, stack *op.RecoveryStack) error
func (p *Provider) CompensateChoose   (activation *op.ActivationRecord, stack *op.RecoveryStack) error
func (p *Provider) CompensateWaitUntil(activation *op.ActivationRecord, stack *op.RecoveryStack) error
```

`Case` (Choose's construction unit) is a pair of subgraphs — a `when` and a `then` — built by `plan.case(when=<body>,
then=<body>)`; a body is an invocation list, a singleton invocation, or a lambda desugared to the `function.call` leaf.

The provider also carries the three **run terminals** (Fallible/plain actions, not combinators):

```go
func (p *Provider) Complete(output any) any
func (p *Provider) Degraded(format string, args []any, kwargs map[string]any) string
func (p *Provider) Failed  (format string, args []any, kwargs map[string]any) error // always a *op.FatalError
```

`plan.complete` passes the run's completion value through; `plan.degraded` renders a degradation message and the run
finishes degraded; `plan.failed` halts execution with a [op.FatalError] and compensation unwinds. Fixture coverage:
test_flow_complete / test_flow_degraded* / test_flow_fatal*; Go unit tests are on step 24's backfill ledger.

## 10. Open questions

1. **Delegate to the Subgraph *method*.** Today `Gather`/`Choose`/`WaitUntil` share Subgraph's body-walk (`walkSubgraphChildren`)
   directly rather than calling `flow.Provider.Subgraph`, because `ActivationRecord.dispatchChild` is unexported and a
   combinator cannot build a per-run activation. A framework affordance to derive a child activation would let the
   combinators call the method and would unify `Subgraph` itself onto the stamped-stack shape.
2. **Public-API gather/choose resume.** A full lifecycle pause-mid-combinator resume test (build a real graph, pause
   mid-flight, save → reload → resume) needs mid-run pause injection; today the per-run path is proven at the unit
   level, and full-run resume skips at the combinator node's own audit receipt. Lands with the eventing API (step 36).
3. **WaitUntil's remaining test-matrix rows (step 12).** Match-after-N-polls needs a fixture-level mutable probe the
   harness lacks; context-cancel and body-error fixtures are unwritten. The container-subgraph realization itself
   landed 2026-07-02.

## 11. Usage — the two planning APIs

Every combinator and terminal is reachable from both planning surfaces: Starlark (`plan.*`, the fixture/author
surface) and the Go planning API (the shared `plan.Provider` — `Plan(name, args, kwargs)` plus the `Case` and
`Variable` constructors — the surface lore builds on). Bodies take the same three shapes everywhere: an invocation
list, a singleton invocation, or (Starlark only) a lambda desugared to the `function.call` leaf.

### Subgraph

```python
w = plan.file.write_text(destination_path="/tmp/out.txt", content="hello", chmod=0o644)
sub = plan.subgraph(body=[w])
```

```go
write, _ := provider.Plan("file.write_text", nil,
	map[string]any{"destination_path": "/tmp/out.txt", "content": "hello", "chmod": os.FileMode(0o644)})
sub, _ := provider.Plan("flow.subgraph", nil, map[string]any{"body": []any{write}})
```

### Gather

```python
body = plan.file.write_text(destination_path=plan.variable("item", default_value=None), content="x", chmod=0o644)
g = plan.gather(items=["/tmp/a.txt", "/tmp/b.txt", "/tmp/c.txt"], limit=2, body=[body])
```

```go
body, _ := provider.Plan("file.write_text", nil, map[string]any{
	"destination_path": provider.Variable("item", nil), "content": "x", "chmod": os.FileMode(0o644)})
g, _ := provider.Plan("flow.gather", nil, map[string]any{
	"items": []any{"/tmp/a.txt", "/tmp/b.txt", "/tmp/c.txt"}, "limit": 2, "body": []any{body}})
```

### Choose

```python
choice = plan.choose(
    plan.case(when=plan.file.exists(resource="/tmp/ready"), then=lambda: "found"),
    default=lambda: "missing",
)
```

```go
when, _ := provider.Plan("file.exists", nil, map[string]any{"resource": "/tmp/ready"})
then, _ := provider.Plan("file.write_text", nil, map[string]any{ /* the chosen branch's work */ })
deflt, _ := provider.Plan("file.write_text", nil, map[string]any{ /* the fallback work */ })
caseValue, _ := provider.Case(when, then) // plan.Provider.Case → flow.NewCase
choice, _ := provider.Plan("flow.choose", []any{caseValue}, map[string]any{"default": deflt})
```

### WaitUntil

```python
ready = plan.wait_until(body=plan.file.exists(resource="/tmp/marker"), timeout="60s", interval="2s")
value = plan.wait_until(body=lambda: "ready", timeout="10s")  # lambda body → function.call leaf
```

```go
probe, _ := provider.Plan("file.exists", nil, map[string]any{"resource": "/tmp/marker"})
ready, _ := provider.Plan("flow.wait_until", nil,
	map[string]any{"body": probe, "timeout": "60s", "interval": "2s"})
```

### Run terminals

```python
plan.complete(output=choice)
plan.degraded("disk space low")
plan.failed("unsupported platform: %s", platform)
```

```go
done, _ := provider.Plan("flow.complete", nil, map[string]any{"output": choice})
warn, _ := provider.Plan("flow.degraded", []any{"disk space low"}, nil)
halt, _ := provider.Plan("flow.failed", []any{"unsupported platform: %s", "plan9"}, nil)
```
