## Thesis

The appnet provider (`pkg/op/provider/appnet`, `op.RoleAction`) is network access for
the graph: one action, `appnet.download`, fetching a URL's response body as bytes. Fallible, not compensable — a
download acquires content; what the plan *does* with the bytes (typically a `file.write_*`) is where compensation
lives.

The resource is the **URL itself**: location-addressed, canonicalized at construction, with `Digest` = SHA-256 of
the URI and `Etag` = the URI — identity of the *address*, deliberately not of the fetched content (the same URL can
serve different bytes over time; content identity belongs to what the plan writes).

## API surface

```go
func (p *Provider) Download(url *Resource) ([]byte, error) // appnet.download(url)
```

## Status

Implemented. The typical composition (`download` → `file.write_bytes`) carries the compensation story.
