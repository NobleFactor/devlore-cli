## Thesis

The json provider (`pkg/op/provider/json`, `op.RoleModule|op.RoleAction`, `+devlore:access=both`) is JSON encoding /
decoding for the operation graph, plus the **content-addressed `json.Resource`**. Two layers:

1. **Value transforms** — `Decode` / `Encode` / `EncodeIndent`: plain fallible conversions between JSON text and Go
   values. No resources, no catalog.
2. **`Parse` → `*json.Resource`** — a parsed document held in memory, identified by the SHA-256 of its **canonical
   form**: the input is parsed and re-marshaled with sorted map keys, no whitespace, stable scalar serialization, so
   two semantically equal inputs (`{"a":1,"b":2}` vs `{"b":2,"a":1}`) produce **identical URIs** (`json:<hex>`) by
   construction. `Parse` is **content-keyed**: same input → the same canonical catalog entry; the first caller's
   unit stamps `producerID`, later same-content callers share the entry unchanged.

Unlike `mem.Resource`'s opaque bytes, a `json.Resource` carries the parsed Go value — validatable against a JSON
Schema or re-encoded without Starlark↔Go round trips.

## API surface

```go
func (p *Provider) Decode(data string) (any, error)                           // json.decode(data)
func (p *Provider) Encode(value any) (string, error)                          // json.encode(value)
func (p *Provider) EncodeIndent(value any, indent string) (string, error)     // json.encode_indent(value, indent)
func (p *Provider) Parse(activationRecord *op.ActivationRecord,
	data string) (*Resource, error)                                           // json.parse(data)
```

`Resource` rehydrates from its URI through the catalog (`UnmarshalJSON` / `UnmarshalText` / `UnmarshalYAML` require
the runtime environment) and answers the addressing surface (`Digest`, content reader, `Equal` by content).

## Status

Implemented in full. Canonicalization caveats: within-Go determinism only; float64 precision; UTF-8 key sort.
